Projeto base para usar nos novos projetos

Para criar a cópia do projeto base, é recomendado usar o degit. Caso não tenha inicie a instalação local:

```
npm install -g degit
```

Clonar projeto base

```
   repositório privado:
   degit --mode=git git@github.com:joao-pedro-pereira-de-souza/setup_nodejs.git .

   repositório público:
   degit https://github.com/joao-pedro-pereira-de-souza/setup_nodejs .

   info:
   degit <diretório do projeto clone> <diretório de saída>

```

documentação do degit:

```
 https://github.com/Rich-Harris/degit

```
